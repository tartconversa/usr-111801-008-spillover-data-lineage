# 景区资料语义

来源可以是主管部门、景区运营方或合作机构。每份原件有来源、字段说明与摘要，产品修订引用原件，交付时按领取方、用途和来源辖区核对许可。受理人员应能区别来源事实、内部编排和已交付凭据。

当前项目围绕景区外消费数据的口径归属开展资料协作。正式公告、复核观察和运营材料各有发布主体；示例记录不代表真实景区状态。

## 口径、空间归属与交付凭据

合作机构提供的交易汇总带有不同时间窗、地理范围和归属许可，不能按同名指标直接相加。台账在来源登记之外提供三层治理：

1. **来源口径（calibers）**：口径按 `(id, revision)` 版本化，记录指标名、指标类别、汇总方式、时间窗、粒度、地理范围单元以及纳入/排除规则。每份交易汇总原件通过 `asset_calibers` 绑定一个口径版本。口径修正另立新版本，旧版本置 `superseded` 保留；已交付快照不被改写，新绑定须显式执行。
2. **空间归属（spatial_units / spatial_relations）**：空间单元有行政/管理层级（父级范围包含子级），单元之间另记 contains/overlaps/adjacent 关系，关系带主张方与生效区间。合作方修正归属时，旧关系置 `superseded` 并封存（记 `effective_to`），新关系通过 `supersedes_id` 接续，修正过程进入审计。
3. **归属许可（attribution_licenses）**：按来源记录署名要求、是否允许表述为"景区带动收入"、使用条件与有效期。同来源颁发新许可时旧许可封存。

## 合并评审与不可合并之处

未发布的产品修订通过 `MergeReview.assess` 评审，结论写入 `product_warnings`：

| 警告代码 | 阻断性 | 含义 |
| --- | --- | --- |
| `caliber_missing` | 阻断 | 原件未绑定口径，无法说明覆盖范围 |
| `attribution_missing` | 阻断 | 来源缺少有效归属许可，引用条件不明 |
| `caliber_mismatch` | 阻断 | 同名指标的汇总方式或纳入/排除规则不同，直接相加混淆口径 |
| `scope_overlap` | 阻断 | 两份输入的地理范围与时间窗重叠且属同类指标，直接相加重复计算 |
| `window_mismatch` | 咨询 | 时间窗不一致，引用时须分别注明覆盖期间 |
| `scenic_claim_restricted` | 咨询 | 许可不允许将该来源消费表述为景区自身收入 |

空间判断同时考虑显式关系和单元层级：父子单元视为包含，overlaps/contains 按无向关系识别。阻断警告未消除时，交付在许可与政策校验之前即被拒绝，拒绝原因进入审计；咨询性警告不阻断，但随交付凭据对外说明。

## 交付凭据与血缘冻结

交付时重新评审（保证合作方的最新修正已反映到未发布修订），通过后：

- 产品修订状态由 `draft` 置为 `published` 冻结，已发布修订不能以新交付编号再次交付，只能按原编号幂等重放；
- `deliveries` 固化三类 JSON 快照：`coverage_snapshot`（每份原件当时绑定的口径全文与空间范围）、`usage_snapshot`（按来源的归属许可、授权编号与政策修订号）、`warning_snapshot`（评审警告）；
- `lineage_digest` 对输入摘要、政策修订与全部快照做哈希，供外部核验回执未被篡改。

此后口径或空间关系再修正，只影响后续新修订；历史回执内容不变，可凭交付编号与审计记录追溯当时口径。
